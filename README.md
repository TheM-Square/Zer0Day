# OIL TWIN — CSS + SRP Decision Support (Baghewala prototype)

A physics-constrained advisory system for **Cyclic Steam Stimulation (CSS)** and
**Sucker Rod Pumping (SRP)** optimization, built as a hackathon prototype for
Baghewala Field (heavy oil, 14–17 °API).

**Advisory only. Not a digital twin. No live SCADA. No autonomous control.**

---

```bash
pip install -r requirements.txt
